/*
=====================================
Arduino Uno 引脚分配
=====================================

数字引脚:
D2  - 按钮输入 (INPUT_PULLUP)
D4  - 左电机方向控制
D5  - 左电机PWM控制 (PWM)
D6  - 右电机PWM控制 (PWM)
D7  - 右电机方向控制
D12 - 蜂鸣器输出
D13 - 状态LED指示灯

模拟引脚:
A0  - 左电磁传感器输入
A1  - 中电磁传感器输入
A2  - 右电磁传感器输入

电源:
5V  - 传感器供电、Logic供电
GND - 公共地线
VIN - 外部12V电源输入 (推荐7.5-12V)

=====================================
L298N电机驱动模块连接
=====================================

Arduino -> L298N:
D4 -> IN1 (左电机方向)
D5 -> ENA (左电机使能/速度)
D6 -> ENB (右电机使能/速度)
D7 -> IN2 (右电机方向)

注意: IN3和IN4可以连接到其他数字引脚扩展为4路电机控制

L298N -> 电机:
OUT1, OUT2 -> 左电机
OUT3, OUT4 -> 右电机

电源:
12V -> L298N VCC (电机电源)
5V  -> L298N 5V (逻辑电源，如果L298N没有内置5V输出)
GND -> 公共地

=====================================
传感器模块连接 (以Hall传感器为例)
=====================================

传感器1 (左侧):
VCC -> 5V
GND -> GND  
OUT -> A0

传感器2 (中央):
VCC -> 5V
GND -> GND
OUT -> A1

传感器3 (右侧):
VCC -> 5V
GND -> GND
OUT -> A2

=====================================
辅助组件连接
=====================================

状态LED:
长脚(+) -> D13
短脚(-) -> GND (通过220Ω电阻)

蜂鸣器:
+ -> D12
- -> GND

按钮:
一端 -> D2
另一端 -> GND
(使用内部上拉电阻，按下时为LOW)

=====================================
电源系统建议
=====================================

方案1 - 单电源系统:
12V电池组 -> Arduino VIN (通过DC插座或VIN引脚)
Arduino内置稳压器提供5V给传感器

方案2 - 双电源系统:
12V电池 -> L298N VCC (电机驱动)
7.4V电池 -> Arduino VIN (控制系统)

方案3 - 降压模块系统:
12V电池 -> 降压模块 -> 5V -> Arduino 5V引脚
         -> L298N VCC

=====================================
安全注意事项
=====================================

1. 确保所有地线连接正确
2. 电机电源与控制电源隔离
3. 添加电容滤波减少电机噪声
4. 使用保险丝保护电路
5. 检查极性避免反接

=====================================
故障排除引脚检查
=====================================

如果系统不工作，请按以下步骤检查:

1. 电源检查:
   - Arduino电源指示灯是否亮起
   - 用万用表测量5V和GND之间电压
   - 检查12V电源是否正常

2. 传感器检查:
   - 串口监视器查看传感器读数
   - 正常范围应在0-1023之间
   - 检测到导线时读数应显著变化

3. 电机检查:
   - 手动转动电机应有阻力
   - L298N指示LED应闪烁
   - 检查接线是否松动

4. 通信检查:
   - 串口监视器应显示启动信息
   - 按钮按下时应有响应
   - LED应根据状态闪烁
*/
