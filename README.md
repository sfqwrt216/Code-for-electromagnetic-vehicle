# 电磁车控制系统 / Electromagnetic Vehicle Control System

这是一个基于Arduino的智能电磁车控制系统，用于循迹和导航控制。

## 功能特点

### 核心功能
- **电磁传感器检测**: 三路高精度电磁传感器检测导线位置
- **智能PID控制**: 自适应PID算法实现精确路径跟踪
- **电机保护**: 内置电机过载保护和软启动功能
- **状态监控**: 实时系统状态显示和错误处理
- **用户交互**: 按钮控制和串口命令支持

### 高级特性
- **传感器校准**: 自动校准功能适应不同环境
- **滤波算法**: 多重滤波确保信号稳定性
- **安全机制**: 紧急停止和看门狗保护
- **调试模式**: 详细的调试信息输出

## 硬件要求

### 必需组件
- Arduino Uno R3 或兼容板
- 3个电磁传感器模块
- 2个直流电机
- 电机驱动板 (L298N推荐)
- 12V电源系统
- 蜂鸣器
- LED指示灯
- 按钮开关

### 接线说明

| 功能 | Arduino引脚 | 说明 |
|------|-------------|------|
| 左传感器 | A0 | 模拟输入 |
| 中传感器 | A1 | 模拟输入 |
| 右传感器 | A2 | 模拟输入 |
| 左电机PWM | 5 | PWM输出 |
| 左电机方向 | 4 | 数字输出 |
| 右电机PWM | 6 | PWM输出 |
| 右电机方向 | 7 | 数字输出 |
| 状态LED | 13 | 数字输出 |
| 蜂鸣器 | 12 | 数字输出 |
| 按钮 | 2 | 数字输入(上拉) |

### 系统状态
- **INIT**: 系统初始化
- **CALIBRATING**: 传感器校准中
- **READY**: 系统就绪，等待开始
- **RUNNING**: 正在运行循迹
- **STOPPED**: 系统暂停
- **ERROR**: 错误状态

## 使用说明

### 1. 首次使用
1. 按照接线图连接硬件
2. 上传程序到Arduino
3. 打开串口监视器 (波特率: 9600)
4. 系统自动初始化

### 2. 传感器校准
1. 短按按钮进入校准模式
2. 手动移动小车经过所有可能路径
3. 等待校准完成提示音
4. 校准数据自动保存

### 3. 开始运行
- **方法1**: 长按按钮2秒直接开始运行
- **方法2**: 先校准，然后短按按钮开始运行
- **方法3**: 串口发送 "START" 命令

### 4. 控制命令

#### 按钮控制
- **短按**: 开始/暂停切换
- **长按**: 直接运行(跳过校准)

#### 串口命令
- `START`: 开始运行
- `STOP`: 停止运行
- `CALIBRATE`: 开始校准
- `STATUS`: 显示系统状态
- `KP=2.5`: 设置比例系数
- `KI=0.1`: 设置积分系数
- `KD=1.0`: 设置微分系数

## 参数调节

### PID参数调节指南

1. **比例系数 (Kp)**
   - 默认值: 2.0
   - 过小: 响应慢，转向不够
   - 过大: 震荡，不稳定

2. **积分系数 (Ki)**
   - 默认值: 0.0
   - 用于消除稳态误差
   - 一般设置较小值

3. **微分系数 (Kd)**
   - 默认值: 1.0
   - 减少超调，提高稳定性
   - 过大会放大噪声

### 建议调节步骤
1. 先调节Kp，观察基本响应
2. 根据需要微调Kd改善稳定性
3. 最后调节Ki消除稳态误差

## 故障排除

### 常见问题

1. **小车不动**
   - 检查电源连接
   - 确认电机驱动板接线
   - 检查代码上传状态

2. **传感器无反应**
   - 确认传感器供电
   - 检查模拟输入引脚连接
   - 重新校准传感器

3. **循迹不准确**
   - 重新校准传感器
   - 调整PID参数
   - 检查导线材质和布置

4. **震荡或不稳定**
   - 降低Kp值
   - 增加Kd值
   - 检查机械装配

### 调试模式
在 `config.h` 中设置 `DEBUG_ENABLED true` 可以查看详细调试信息。

## 技术规格

- **控制频率**: 20Hz
- **传感器精度**: 10位ADC (0-1023)
- **电机控制**: PWM调速 (0-255)
- **响应时间**: < 50ms
- **工作电压**: 7-12V
- **最大速度**: 可配置 (默认255)
